ESTIMATION / CHAPTER 25

信息论工具实战：把熵和互信息算对

公式简洁，估计却充满陷阱：离散熵在小样本下系统性偏低，连续互信息依赖带宽或邻域数，神经估计器给的是下界而非测量值。这一章按"数据是离散还是连续、要报告统计量还是要优化目标"两条线，把每种方法的偏差方向和适用边界讲清楚。

估算信息量为什么容易出错？

前 24 章的熵、互信息、KL 散度都是对真实分布的量，而实践中我们拿到的是一批样本。用样本去近似分布会引入偏差（bias）和方差（variance），而且偏差的方向取决于方法与样本量。一个常见的翻车场景：用固定箱数的直方图估计高维特征与目标的互信息，因为格子稀疏，几乎所有估计都接近 0，于是"最有信息量的特征"被判为无用。

本章的主线只有一句：先分清你要的是可报告的统计量，还是可优化的目标函数。前者要求偏差小、方法可复现；后者只需朝着正确的方向推动。混淆二者，就会把训练目标当成测量值写进论文。

离散变量：经验频率与有限样本偏差

若变量的取值集合有限且样本充足，最直接的做法是用经验频率 p̂(x)=n_x/N 代入定义：

H^=−∑xp^(x)log2p^(x)
(25.1)

这个估计量是有偏的，而且总是偏低：没出现过的符号被赋了零概率，但它的真实概率未必是零。例：抛公平硬币 10 次全为正面，经验熵为 0，而真实熵是 1 bit。偏差随类别数 m 增大、随样本数 N 减小。一个经典的渐近近似是：

E[H^]−H≈−m−12Nln2
(25.2)

常用校正手段：Miller-Madow 校正在经验熵上加上 (m̂−1)/(2N)（自然对数；换成 bit 需再除以 ln2），其中 m̂ 是观测到的类别数；刀切法（Jackknife）依次留出一个样本重估以削减偏差；贝叶斯/Dirichlet 先验避免零概率，思想与 label smoothing 相通。经验法则是每个类别平均至少 5–10 个样本；若类别数远超样本数，任何校正都救不了你。

式 (25.2) 是渐近近似，不是对所有分布都精确成立。报告熵估计时，除了数值还应给出样本量、类别数与所用校正方法。
N=20：m=8 时经验熵平均低估约 0.253 bit（渐近近似），而真实熵为 3.000 bit

按式 (25.2) 计算 m=8 符号（真实熵 3 bit）时的平均低估量。N 越大越低，但收敛很慢——这就是小样本熵估计必须校正的理由。

连续变量的互信息估计

连续变量没有可数的取值集合，联合密度 p(x,y) 无法从有限样本直接得到，所以"直接计数"失效。三条常见路线：

  • 分箱（binning）：把每个变量离散化后按离散公式算。实现简单，但箱数太少会低估、太多会因稀疏而高估，且箱数随维度指数增长。
  • KSG 估计器（Kraskov–Stögbauer–Grassberger）：基于 k 近邻，利用联合空间与边缘空间中邻域计数的差异估计互信息，无需显式估密度，对箱数不敏感，在中等维度（约 d≤20）下是常用基准。
  • KDE：先用核函数拟合密度再积分，精度高但计算量大（O(N²) 量级），且对带宽敏感，一般只用 d≤5。

式 (25.3) 给出互信息的定义，它也是以上所有估计量的目标（对连续变量积分代替求和）：

I(X;Y)=∬p(x,y)log2p(x,y)p(x)p(y)dxdy
(25.3)
无论哪种方法，样本量不足时互信息的估计都会失真。报告结果时至少应给出方法、参数（箱数/k/带宽）、样本量和置信区间，并做置换检验区分"真相关"与"纯噪声"。

神经估计器：MINE 与 InfoNCE

2018 年起，用神经网络估计互信息成为热点。MINE（Belghazi 等）基于 Donsker–Varadhan 表示，把互信息写成对某函数 f 的上确界：

I(X;Y)=supfEp(x,y)[f(x,y)]−logEp(x)p(y)[ef(x,y)]
(25.4)

InfoNCE（van den Oord 等）来自对比学习，用"正样本对 vs 负样本对"的分类任务给出互信息的下界；SimCLR、MoCo、CLIP 等模型的核心损失正是它。

MINE 与 InfoNCE 是训练代理，不是无偏测量工具。它们给出的是下界，且 MINE 训练不稳定——不同随机种子可能给出完全不同的值。需要报告互信息数值作为统计量时，应使用 KSG 或 infomeasure；把 MINE/InfoNCE 当作优化目标函数才是它们的正确用途。

infomeasure 与统计显著性

2025 年发表的 infomeasure 库在 Scientific Reports 提供了一个统一 API：用同一套接口估计熵、互信息、传递熵、KL 散度，并可选择估计器（KSG 等），避免在不同库之间反复切换。它还提供置换检验给出 p 值，用于区分"真相关"与"纯噪声"——当估计出的互信息很小时，这一点尤其重要。

报告结果时的最小清单：方法名与版本、估计器参数（k 或箱数/带宽）、样本量、置信区间或置换检验 p 值，以及数据的实值/离散类型。缺了这些，一个互信息数值几乎无法被复现或比较。

可测试的最小算例

下面用纯 Python 核对式 (25.1) 与式 (25.2)（教学示意，固定值断言）：

import math
def entropy(ps): return -sum(p*math.log2(p) for p in ps if p > 0)
# 公平硬币：真实熵为 1 bit
assert abs(entropy([0.5, 0.5]) - 1.0) < 1e-12
# 观测到 10 次全为正面：经验熵为 0，但这是有偏估计
assert entropy([1.0, 0.0]) == 0.0
# m=8, N=20 时的渐近低估量（bit）
bias = (8 - 1) / (2 * 20 * math.log(2))
assert abs(bias - 0.2525) < 1e-3

以上仅校对定义与偏差公式的数值，不构成对任意数据集的估计承诺；真实数据的偏差还取决于分布形状与估计器参数。
