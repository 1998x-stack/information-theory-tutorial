CONVOLUTIONAL CODES & VITERBI / CHAPTER 17

卷积码与 Viterbi：网格上的最优路径

从 K=3、(7,5) 卷积编码器的状态约定开始，推导 trellis、分支度量和 Add–Compare–Select，并用硬判决译码器验证单比特扰动。

连续比特流没有固定块边界，怎样利用过去的输入纠错？

分组码把固定长度的消息块映射为码字；卷积码则让编码器持续读取输入流，并把最近若干输入位保存在移位寄存器中。当前输出既依赖当前输入，也依赖寄存器状态，因此整个编码器是一台有限状态机。

接收端面对带噪输出，需要从所有可能的输入序列中找到最可能的一条。直接枚举 T 个输入位的 (2^T) 种序列会迅速失控。Viterbi 算法利用网格图和动态规划，只为每个状态保留一条累计度量最小的幸存路径。

本章固定一个可复现约定：二进制输入、码率 1/2、约束长度 K=3、生成多项式 (7,5) 八进制；状态写作 (uₜ₋₁,uₜ₋₂)，初始状态为 00。更换寄存器位序时，分支输出表也必须同步变化。

(7,5) 编码器：当前位和两个记忆位产生两位输出

令状态为 (s_t=(u_{t-1},u_{t-2}))。输入新比特 b 后，两个输出为 (v_0=boplus u_{t-1}oplus u_{t-2})、(v_1=boplus u_{t-2})，下一状态为 (s_{t+1}=(b,u_{t-1}))。两个生成多项式分别是 111₂=7₈ 和 101₂=5₈。

v_0=b⊕s_1⊕s_0,\quad v_1=b⊕s_0,\quad s'=(b,s_1)
(17.1)

约束长度 K=3 表示当前输入与两个记忆位共同参与输出；状态数为 (2^{K-1}=4)。未终止的流式编码可一直运行；若希望有限帧从零状态开始并回到零状态，通常附加 K−1 个尾比特，这会带来有限帧开销。

状态转移表：分支标注“输入 / 输出”

四个状态为 00、01、10、11。每个状态有输入 0 和输入 1 两条出边。由于状态只包含最近两位，走过两步后，较早的路径历史已被状态吸收；这就是不同路径可能在同一状态重新汇合的原因。

当前状态输入 0：输出 → 下一状态输入 1：输出 → 下一状态
0000 → 0011 → 10
0111 → 0001 → 10
1010 → 0101 → 11
1101 → 0110 → 11

Viterbi：累积分支度量，在每个状态执行 ACS

对于硬判决 BSC，接收端每次收到两位 rₜ，分支度量可以取输出与 rₜ 的汉明距离。候选路径的累计度量等于前一状态路径度量加当前分支度量。若多条路径到达同一下一状态，只保留累计度量最小者。

M_t(s')=\min_{s,b:\,T(s,b)=s'}\{M_{t-1}(s)+d_H(r_t,v(s,b))\}
(17.2)

初始化时只有状态 00 的度量为 0，其余为无穷大。对终止码字，最终选择状态 00 并回溯；对未终止流，常选择度量最小的终态或采用连续译码。译码路径是否终止，是编码器边界约定的一部分。

手算一段序列：1011 加两个尾零

输入数据 1011，附加两个尾比特 00，使 K−1 个记忆位清零。按本章约定，编码输出为 111000010111。如果第 6 个编码位翻转，接收串为 111001010111；硬判决 Viterbi 译码仍恢复消息 1011，最小路径度量为 1。

from examples.advanced_information import conv_encode, viterbi_decode
message = "1011"
encoded = conv_encode(message, terminate=True)
assert encoded == "111000010111"
received = encoded[:5] + ("1" if encoded[5] == "0" else "0") + encoded[6:]
decoded = viterbi_decode(received, terminate=True)
assert decoded == message
print(encoded, received, decoded)
接收 111001010111；硬判决 Viterbi 解码为 1011；路径度量 1

固定消息 1011、尾零 00、生成多项式 (7,5)，使用硬判决汉明分支度量和终态 00。

硬判决与软判决：度量函数由信道统计决定

硬判决把接收模拟值先切成 0/1，再使用汉明距离。软判决保留接收样本的幅度或对数似然比；在 AWGN+BPSK 等模型下，可以使用欧氏距离或负对数似然作为分支度量。若软信息保留了“这个比特更像 0 还是 1”的置信度，译码通常能比过早硬切片更有效。

状态数为 (2^{K-1})，每个状态有 2 条分支；每个时刻的 ACS 运算量随状态数线性增长。实际实现还要设计幸存路径存储、回溯深度、度量归一化和连续译码延迟。

不能把 Viterbi 算法说成“对任何序列模型都能找到真实序列”。它在给定 trellis、初始/终止状态和正确分支概率模型下执行最大似然路径搜索；若模型或边界假设错误，最优路径也只是相对于错误模型的最优。

应用历史要区分码参数、标准版本和具体系统

卷积码与 Viterbi 译码长期用于深空链路、卫星、蜂窝和早期无线 LAN。工程标准往往使用更长约束长度、打孔、交织、软输入译码，或与 Reed–Solomon 等外码级联；不能只凭“生成多项式相同”就认定两个系统的帧结构、码率和译码性能完全相同。

本章 K=3 的 (7,5) 示例专门用于解释状态和动态规划，不代表现代蜂窝或 Wi‑Fi 的完整物理层编码方案。
