互信息

互信息不是线性相关系数，而是知道一个随机变量后，另一个变量的平均不确定性减少了多少。

知道观测 Y，能少猜多少关于 X 的事情？

把 X 视为发出的比特、Y 视为信道输出。若信道没有噪声，看见 Y 就能确定 X；若 Y 与 X 完全独立，则观察 Y 没有帮助。介于两者之间的帮助程度，就是互信息 I(X;Y)。

互信息衡量的是概率依赖，包含非线性关系，并不要求 X 与 Y 的数字编码具有某种特定大小关系。

先看联合分布，再看边缘分布

考虑输入 X 为公平比特，信道以 ε=0.1 的概率翻转比特。于是 p(0,0)=p(1,1)=0.45，p(0,1)=p(1,0)=0.05，四项相加为 1。每一行与每一列的边缘概率都是 0.5。

从剩余不确定性定义互信息

互信息既可写成熵的差，也可写成联合分布与两个边缘分布乘积之间的 KL 散度。对有限离散变量有：

I(X;Y)=H(X)−H(X|Y)
(4.1)

这一定义是对“有了 Y 能减少多少关于 X 的未知”最直接的表述。若二者独立，H(X|Y)=H(X)，则 I(X;Y)=0；若 Y 决定 X，则 H(X|Y)=0，互信息达到 H(X)。

I(X;Y)=∑x,yp(x,y)log2p(x,y)p(x)p(y)
(4.2)

带噪二元信道：具体算出 0.531 bit

对输入均匀的二元对称信道，X 的熵为 1 bit，且给定 Y 后 X 的条件熵就是翻转噪声的二元熵 h₂(ε)。所以 I(X;Y)=1−h₂(ε)。当 ε=0.1 时，h₂(0.1)≈0.469，互信息约为 0.531 bit。

I(X;Y) = 0.5310 bits

只针对输入均匀的二元对称信道；ε 取 0 到 0.5 的区间。

from math import log2
h2 = lambda p: 0 if p in (0, 1) else -p*log2(p)-(1-p)*log2(1-p)
assert abs((1-h2(.1)) - .5310044064) < 1e-8
assert 1-h2(.5) == 0

相关性为零，也可能存在信息

设 X 在 −1、0、1 中等概率取值，令 Y=|X|。由于对称性，E[X]=0 且 E[XY]=0，所以 Pearson 相关系数为 0；但是 Y 是 X 的确定函数，I(X;Y)=H(Y)=h₂(1/3)≈0.918 bit。零线性相关不意味着统计独立。

互信息对变量做一一映射不变；但从有限数据估计互信息则有挑战，尤其在高维连续场景中。

数据处理不等式：加工不会创造关于原信号的新信息

若 X→Y→Z 构成马尔可夫链，即在给定 Y 时 Z 与 X 条件独立，则 I(X;Z)≤I(X;Y)。这并不是说任何增加特征的算法都绝不可能提高预测指标，而是说在给定概率模型与变量定义下，后续仅基于 Y 的随机处理不能增加关于 X 的互信息。

常见陷阱：把任意三个变量画成箭头，并不足以调用数据处理不等式；必须证明或假设条件独立结构。
