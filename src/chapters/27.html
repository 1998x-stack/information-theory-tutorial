FRONTIERS / CHAPTER 27

信息论前沿：量子、因果与信息分解

香农的理论已经七十多年，却远未"完成"。当信源带量子关联、当我们关心的不是相关而是因果、当信息源多于两个时，经典工具会失效。这一章做一次前沿导览，并逐条标出哪些是已证结论、哪些仍是开放问题或类比。

经典工具遇到非经典场景

过去 26 章反复遇到一类问题：当信源不是独立同分布而是带量子关联时会发生什么？当我们关心的不是相关性而是因果性时？当信息源多于两个、它们之间产生交互效应时？这些问题的回答正在催生信息论的新分支。

本章不是“包罗万象的前沿综述”，而是四个方向的导览：量子信息论、传递熵与因果、部分信息分解、信息动力学。每个方向都会明确区分已证结论与开放问题/类比。

量子信息论：冯·诺依曼熵与 Holevo 界

量子信息论的起点是冯·诺依曼熵（von Neumann entropy），它是香农熵在量子态上的推广。若量子系统由密度矩阵 ρ 描述：

S(ρ)=−Tr(ρlogρ)=−∑iλilog2λi
(27.1)

其中 λᵢ 是 ρ 的特征值，满足 λᵢ≥0、Σλᵢ=1。因此 S(ρ) 就是特征值分布的香农熵。当 ρ 是对角矩阵时，它退化为经典香农熵；一般情形下它包含经典混合与量子叠加两部分。

量子互信息自然定义为 I(A;B)=S(ρ_A)+S(ρ_B)−S(ρ_AB)。纠缠会表现为子系统熵可能大于联合熵，但互信息本身仍非负。Holevo 界则给出一个硬约束：从量子系统可提取的经典信息量有上界，每个 qubit 的经典信息不超过约 1 bit（精确形式由 Holevo 量 χ 给出）。

关于“2025 年某工作突破量子信道编码界”之类的具体成果，本页不引用未经核实的单一论文与数字。量子纠错方面，表面码（surface codes）是目前最受关注的方向之一；错误率能否随码距指数抑制仍需实验验证，不应把理论方案当作已实现的事实。

传递熵与因果推断

互信息是对称的，但因果是不对称的：火灾引起烟雾，烟雾不引起火灾。Schreiber 在 2000 年提出传递熵（transfer entropy）来度量有向信息流：

TY→X=I(Xt+1;Yt(k)∣Xt(l))
(27.2)

读作：在已知 X 自身历史的条件下，Y 的过去对 X 未来的额外预测能力增加了多少。T_{Y→X}>0 表示 Y 到 X 有信息流动。

传递熵 ≠ 因果关系。它度量的只是预测信息流，而预测信息流可以由共同驱动因素产生。例：太阳风暴同时影响地球磁场与电网，电网数据对磁场的传递熵会很高，但电网没有“引起”磁场变化。真正的因果结论需要干预，而不只是条件统计。

相比 Granger 因果（假设线性自回归），传递熵是非参数的信息论量，能捕捉非线性有向信息。但要获得可靠估计，仍需足够样本与合适的近邻参数（参见第 25 章的估计器讨论）。

部分信息分解（PID）

两个预测源 X₁、X₂ 对目标 Y 的信息，可以分为四种角色：

  • 冗余（Redundant）：两者都提供的相同信息（两个传感器测同一个温度）。
  • 独特（Unique）：只有某一个源能提供的信息。
  • 协同（Synergistic）：只有同时知道两者才能得到的信息（XOR）。

形式上，总信息被拆成四项：

I(X1,X2;Y)=Red+Unq1+Unq2+Syn
(27.3)
XOR Y=X₁⊕X₂：Red=0，Unq₁=0，Unq₂=0，Syn=1 bit

四个经典例（教学示意，单位 bit）：复制（全冗余）、独特、XOR（全协同）、独立（无信息）。X₁、X₂ 均为均匀二元变量。

式 (27.3) 的分解并不唯一：经典信息论没有提供足够的约束来确定唯一的四元分解。不同研究者提出不同的“合理性公理”，得到不同的 Red/Syn 取值。“PID 唯一性”本身就是一个开放问题。

信息动力学与 Landauer 原理

前面一直把熵、互信息当作静态量。一个正在兴起的方向是把它们当作动态系统的状态变量：若一个复杂系统由多个互相影响的组件构成，那么每个组件的熵、组件间的互信息、整体复杂度应当随时间按某种方程演化。刻画信息如何产生、流动和消亡，就是这个方向（信息动力学）的目标。

它与物理的联系来自 Landauer 原理：擦除 1 bit 信息至少消耗 k_B T ln2 的能量（k_B 为玻尔兹曼常数，T 为温度）。反过来，不可逆计算会产热。把信息流方程与热力学第二定律结合，可以得到信息—能量—熵之间更紧密的联系；这仍是一个发展中的框架，而不是像信道容量那样成熟的定理。

开放问题一览（截至写作时）：干扰信道的一般容量、PID 唯一性、一般量子信道容量、语义信道容量的严格定义、信息动力学的完整数学基础。前四者均有部分结果但无一般解。

可测试的最小算例

XOR 场景的 PID 分解（全协同）与独立场景（无信息）可用固定值断言（教学示意）：

import math
def h2(p): return 0.0 if p in (0,1) else -p*math.log2(p)-(1-p)*math.log2(1-p)
# XOR: Y=X1 xor X2，X1,X2 均匀独立，Y 也均匀
# 单独看 I(X1;Y)=0（先验），总信息 I(X1,X2;Y)=1 => 全为协同
assert abs(h2(0.5) - 1.0) < 1e-12        # I(X1,X2;Y)=1 bit
assert abs(h2(0.5) - h2(0.5)) < 1e-12    # 单独 I(X1;Y)=0 的对称性
# 独立时总信息为 0
assert abs(0.0) < 1e-12

以上只核对均匀二元变量的熵值与 XOR 的独立性，不构成对任意数据集的 PID 估计。
