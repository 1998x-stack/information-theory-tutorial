REPRESENTATION LEARNING / CHAPTER 24

信息瓶颈：好的表示既压缩又预测

一个深层网络有很多层参数，它到底在"学"什么？信息瓶颈（IB）给出一个可量化的回答：在尽量少保留输入 X 的信息 I(X;T) 的同时，尽量多保留关于输出 Y 的信息 I(T;Y)。这一章讲清这个原则、它在信息平面上的两阶段现象，以及由此引出的争议与实用变体 VIB。

为什么需要一个"压缩"原则？

用 MSE 训练的模型可能把训练集的每个细节都记下来，训练损失很低，换成测试集却一塌糊涂。直觉上说，好的表示应当丢掉与任务无关的细节，只留下能预测目标的部分。信息瓶颈（Information Bottleneck, IB）把这个直觉写成了可以计算的优化问题：表示 T 是输入 X 的一个"有损压缩"，压缩的程度由互信息 I(X;T) 度量，而任务相关性由 I(T;Y) 度量。

需要先说清假设：T 只通过 X 影响 Y，即马尔可夫链 X→T→Y。这样 I(T;Y) 不会超过 I(X;Y)，任何表示都不可能凭空获得关于 Y 的信息——数据处理不等式（第 4 章）保证了这一点。

信息瓶颈原则

考虑三个随机变量：输入 X、表示 T、目标 Y。IB 原则要求在保底的相关性约束下把压缩做到极致：

minI(X;T)s.t.I(T;Y)≥I0
(24.1)

用拉格朗日乘子把它写成无约束形式，就是 IB 的目标函数：

LIB=I(X;T)−βI(T;Y)
(24.2)

β 控制权衡：β→0 时只关心压缩，表示趋于常数；β→∞ 时只关心预测，表示尽量保留 X 的全部信息。适中的 β 才在两者之间取到折中。

IB 与率失真理论（第 19 章）是近亲：两者都在给定信息预算下最小化"损失"。区别在于，率失真的失真度量 D 是人为给定的函数，而 IB 的失真由关于 Y 的信息损失自动定义——这是一个任务驱动的自适应压缩。当 Y 与 X 的联合分布退化时，IB 就回到率失真。

深度学习中的信息平面

2017 年 Tishby 与 Zaslavsky 用"信息平面"分析网络：对每一层激活值 T 计算 I(X;T) 与 I(T;Y)，把每层画在平面上，横轴是压缩率、纵轴是相关性。他们报告的轨迹分为两个阶段：

  1. 拟合阶段：训练初期，各层的 I(X;T) 与 I(T;Y) 同时快速上升，对应训练准确率提升。
  2. 压缩阶段：训练后期，I(X;T) 开始下降而 I(T;Y) 保持或微升，网络丢弃输入中的无关细节。

这个解释之所以吸引人，是因为它给"为什么能泛化"提供了一个信息论叙事：网络并非在记忆训练数据，而是在做任务驱动的有损压缩。但互信息在连续高维空间中的估计极难，这一实验的可重复性存在争议——这正是下一节的焦点。

争议：tanh 伪影还是普遍现象？

2018 年 Saxe 等人对上述实验提出强烈质疑，他们指出观测到的"压缩阶段"可能与激活函数类型密切相关：

  • 当使用 tanh 激活时，训练后期神经元输出饱和到平坦区，激活值被离散化，这会人为地降低互信息的估计值，看上去像"压缩"。
  • 换成 ReLU 激活时，他们没有观察到明显的压缩阶段，I(X;T) 保持高位或继续上升。

另一个根源是互信息估计本身：Tishby 的实验用分箱（binning）估计连续互信息，而高维分箱的偏差会歪曲结果。把"观测到的轨迹"当成"网络固有规律"是危险的。这不是说 IB 无价值：作为损失函数的设计工具，变分信息瓶颈在实践中确实有效；作为一个关于泛化的解释性假说，它仍未被完全证实。区分这两种角色，是本页最重要的认识。

压缩阶段是否在 ReLU 网络中存在、是否只是训练轮数不够的问题，至今仍有争论。在报告中给出信息平面时，应写明互信息估计方法与激活函数，不要把估计伪影当作结论。

变分信息瓶颈与率失真

IB 目标里的 I(X;T) 与 I(T;Y) 在连续高维情形下都难算。变分信息瓶颈（Variational Information Bottleneck, VIB）用两个变分分布近似：编码器 q(t|x) 近似 p(t|x)，解码器 r(y|t) 近似 p(y|t)，得到一个可优化的下界：

LVIB=Eq(t∣x)[logr(y∣t)]−βDKL(q(t∣x)∥p(t))
(24.3)

把它和第 23 章 VAE 的损失并排看：第一项是重构/预测的对数似然，第二项是 KL 正则。唯一区别是可以调节 β。实际上 VAE 可看作 VIB 的一个特例——两边都是生成式时就是 VAE；VIB 的编码器则可以是任意的任务编码器。KL 项就是"率"，预测误差就是"失真"，整个式子重新回到了第 19 章的率失真权衡。

可测试的最小算例

为了把"压缩与预测"变成可断言的东西，考虑一个四符号信源（教学示意，不是通用证明）：X 取 {0,1,2,3} 等概率，Y 是 X 的奇偶位 X mod 2，B 是高位。由于 Y 是 X 的函数，I(X;Y)=H(Y)=1 bit，而冗余信息 B 也可以被保留或丢弃。下列四个确定型表示给出不同的工作点：

  • 常数 T：I(X;T)=0，I(T;Y)=0
  • 仅保留 Y：I(X;T)=1，I(T;Y)=1（率最低且相关性饱和，帕累托最优点）
  • 保留 B：I(X;T)=1，I(T;Y)=0（花了同样的率却丢掉了相关性）
  • 保留全部 X：I(X;T)=2，I(T;Y)=1（多出的 1 bit 对预测毫无帮助）
β=1.5 时最优表示：仅保留 Y；I(X;T)=1.00，I(T;Y)=1.00，目标 =−0.50

在四个候选表示中取使 I(X;T)−β·I(T;Y) 最小者。β 小于 1 时压缩占主导（选常数）；β 大于 1 时相关性占主导（选仅保留 Y）。"保留全部 X"在任何 β 下都不是最优，因为它浪费了率。

这个例子里的候选表示都是确定型映射，因此其信息曲线是离散的点；真正的 IB 最优曲线允许 T 随机依赖 X，需用 Blahut-Arimoto 型迭代求解。本仓库样例代码用固定点断言离散熵与互信息的初等计算，可作为校对的参照：

import math
def h(ps): return -sum(p*math.log2(p) for p in ps if p > 0)
pX, pY = [0.25]*4, [0.5, 0.5]          # X 均匀；Y = X mod 2
joint = [[0.25,0.0],[0.0,0.25],         # p(x,y)
         [0.25,0.0],[0.0,0.25]]
I = sum(joint[x][y]*math.log2(joint[x][y]/(pX[x]*pY[y]))
        for x in range(4) for y in range(2) if joint[x][y] > 0)
assert abs(h(pX) - 2.0) < 1e-9
assert abs(h(pY) - 1.0) < 1e-9
assert abs(I - 1.0) < 1e-9              # I(X;Y) = H(Y) = 1

全为初等运算，不依赖任何第三方库；以上为教学示意计算，用来校对熵与互信息的定义，不构成对任意数据集的估计承诺。
