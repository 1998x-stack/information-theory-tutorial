综合项目：把 28 章串成一条链路

理论最终要落到"动手做"。这一章用三个递进的项目收束全课程：先做熵与互信息的计算器，再对比三种无损压缩算法，最后搭一个端到端通信系统。每个项目都给出可复现的骨架与固定断言，并说明"哪里只是教学示意、哪里是可报告的结论"。

起点：先了解你的数据

一个常见的坑：实现了 Huffman 编码，对一段英文文本压缩，结果压缩比只有 1.1:1，几乎没压。排查后发现——编码前忘了统计输入的概率分布，而是假设每个字符等概率出现。这等于你试图压缩一段高度偏斜的数据，却事先认为它可能是任何东西。

这件事教了一课：信息论的起点永远是“了解你的数据”。不知道信源的分布，任何编码方案都是空中楼阁。本页的三个项目就从这里开始。

项目一：熵与互信息的计算器

第一个项目是把前几章分散的公式做成一个可复用的工具，支持：

  • 从离散分布计算熵 H(X)、联合熵 H(X,Y)、条件熵 H(X|Y)、互信息 I(X;Y)、KL 散度 DKL(P∥Q)；
  • 从样本数据估计上述量（连续变量用 KSG 或 KDE，参见第 25 章的偏差讨论）；
  • 用信息 Venn 图展示熵、条件熵与互信息的关系。

核心实现就是你已经在前面见过的定义式；下面这个固定分布的例子可以直接断言（教学示意）：

from examples.coding import entropy
p = {"A": 0.4, "B": 0.3, "C": 0.2, "D": 0.1}
H = entropy(p.values())
assert abs(H - 1.8464393) < 1e-6   # 理论熵（bit）

把“统计 → 代入公式 → 与理论值对账”做成一个可重复的流程，是后面两个项目的基础。先用一个 Huffman 最小例子感受“熵下界”与“实际平均码长”的差距：

H ≈ 1.8464；Huffman L=1.9000 bits（A:1 B:2 C:3 D:3）

无论 p(A) 如何变，总有 H ≤ L < H+1。权重相同时可有不止一种最优树。

项目二：无损压缩算法对比

一切无损编码都受信源编码定理的约束：平均码长不可能低于熵，但可以任意接近它。

H(X)≤L<H(X)+1
(28.1)

三种无损算法（Huffman、算术编码、LZW）在三种数据上系统对比：英文文本、只含 {A,C,G,T} 的 DNA 序列、均匀随机字节（作为 baseline——理论上不可压）。关键观察：

  • DNA 序列字母表只有 4 个，Huffman 接近熵极限（每符号约 2 bit）。
  • 英文文本上算术编码通常优于 Huffman，因为它不要求每个符号整数个 bit。
  • 随机数据不可压，LZW 在随机数据上反而会膨胀（词典条目占位）。
报告压缩比时必须同时给出数据来源、数据大小、是否包含编码表开销。不同论文中“压缩比”的定义往往不同，只比较单一数字容易得出错误结论。

项目三：端到端通信系统

最终项目把前面所有概念串成一个完整链路：信源编码 → 信道编码 → 信道（叠加噪声） → 信道译码 → 信源译码。每一级都是你学过的独立模块。

模块可选实现参考章节
信源编码Huffman / 算术编码 / 游程编码第 9–10 章
信道编码Hamming(7,4) / 卷积码 + Viterbi第 15–17 章
信道BSC / AWGN第 12–13 章
性能评估BER–SNR 曲线 / 压缩比 / 端到端延迟第 14 章
ε=0.10，均匀输入互信息=0.5310 bit/次

展示的 I(X;Y) 仅对应均匀输入；BSC 因对称性恰好在均匀输入时取得容量。要比较编码前后，就对应到相同 ε 下的两种误码率。

信道编码不会降低信道本身的噪声，它只是用“受控冗余”把错误集中到可纠正的位置。当码率 R 超过容量 C 时，任何码都不可能把错误概率压到零——这就是信道编码定理的反向部分。

可测试的最小算例

三个项目的核心断言可以压成一段可运行的代码（依赖仓库的 examples/ 模块）：

from examples.coding import entropy, huffman_codebook
from examples.channel_coding import (
    hamming74_encode, hamming74_syndrome, hamming74_correct)

p = {"A": 0.4, "B": 0.3, "C": 0.2, "D": 0.1}
H = entropy(p.values())
code = huffman_codebook(p)
L = sum(p[s] * len(code[s]) for s in p)
assert H <= L < H + 1                       # 信源编码定理的界

cw = hamming74_encode("1011")
assert hamming74_syndrome(cw) == 0           # 合法码字
flipped = cw[:4] + ("1" if cw[4] == "0" else "0") + cw[5:]
assert hamming74_syndrome(flipped) == 5      # 第 5 位出错
assert hamming74_correct(flipped) == cw      # 单错可纠回

断言基于仓库 examples 模块的固定输出；它们校对的是定义与算法行为，不是任何数据集上的压缩率或误码率承诺。
